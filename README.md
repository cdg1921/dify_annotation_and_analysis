
## Introduction

本项目为开源项目DIFY源码注释与解析（[源码链接](https://github.com/langgenius/dify/)），以帮助更多的同学学习和理解DIFY源码，以便更快地进行二次开发和优化。

DIFY作为MaaS平台的最佳实践，其架构设计以及编程习惯，对于希望从事AI应用开发或者python开发的同学来说，也是一个非常不错的学习项目，非常值得学习和借鉴。

main分支对应的源码版本为0.15.3版本。其他版本会有些差异，但不影响整体理解。
其他版本只对有差异的代码进行注释，并保存在相应相应的分支中（如MCP服务相关代码注释保存在1.6.0分支中）。 

所有注释内容均以“# cdg:”开头。
